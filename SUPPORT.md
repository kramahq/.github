# Getting help

- **Questions and ideas:** use GitHub Discussions on the [krama](https://github.com/kramahq/krama) repository.
- **Bugs:** open a bug report with the issue form.
- **Docs:** https://github.com/kramahq/krama-docs
- **Security issues:** see [SECURITY.md](SECURITY.md); never post them publicly.

This is a community project; there is no guaranteed response time.
