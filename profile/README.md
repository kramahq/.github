# Krama

An open-source, A2A-native factory that turns packaged, versioned agent teams into reviewed deliverables.

- **[krama](https://github.com/kramahq/krama)**: the platform
- **[krama-packs](https://github.com/kramahq/krama-packs)**: first-party packs
- **[krama-docs](https://github.com/kramahq/krama-docs)**: documentation

Status: early development.
