# Krama

An open-source, A2A-native factory that turns packaged, versioned agent teams into reviewed deliverables.

- **[krama](https://github.com/kramahq/krama)**: the platform
- **[krama-packs](https://github.com/kramahq/krama-packs)**: first-party packs
- **[krama-docs](https://github.com/kramahq/krama-docs)**: documentation

## Get involved

- Read the [contributing guide](https://github.com/kramahq/.github/blob/main/CONTRIBUTING.md) and pick a `good first issue`.
- Ask questions in [Discussions](https://github.com/kramahq/krama/discussions).
- Propose big changes through the [RFC process](https://github.com/kramahq/.github/blob/main/GOVERNANCE.md).
- Report vulnerabilities privately: [SECURITY.md](https://github.com/kramahq/.github/blob/main/SECURITY.md).
